FITZONE BASIC — HIGH NET WEBSTUDIO DEMO
=======================================

This is a fictional, single-page gym website with light interactions.
It is built with separate HTML, CSS, and JavaScript files; no framework or backend is required.

GET STARTED
1. Open this folder in Visual Studio Code.
2. Open index.html with Live Server, or double-click it to preview locally.
3. For the portfolio demo gallery, move the fitzone-basic folder into:
     High_Net_Webstudio_V3/demos/fitness/fitzone-basic/
4. In the main portfolio's demos.js, find the FitZone entry and set:
     url: "demos/fitness/fitzone-basic/index.html"
5. For a matching preview image, overwrite assets/previews/fitzone-basic.webp in your main portfolio with the provided preview thumbnail if available.

CUSTOMIZE
- index.html: homepage copy, membership cards, sample hours and FAQ.
- style.css: colors, fonts, spacing, mobile layout, minimal transitions.
- script.js: PROGRAMS array, TIMETABLE object, filters, dialogs and enquiry preview.
- assets/: original editable SVG illustrations and matching local WebP card graphics. Everything displays offline; Google Fonts fall back to system fonts if unavailable.

DEMO NOTES
- The gym, prices, trainers, hours and facilities are fictional examples.
- The enquiry form creates a preview only; no personal details are submitted, stored or sent.
- There is no payment or live class-booking system.
- A real client version would need a verified address, working contact method, accurate pricing and class times.
