QUICK ANSWERS

A few things
worth knowing.

Curious about starting? These example answers cover the questions people usually ask first.

Do I need gym experience to join?+

Not at all. The sample studio offers a friendly introduction to the training spaces and equipment.

Can I try different classes?+

The Gym + Classes example plan includes access to different group sessions listed in the timetable.

How can I find a class that suits me?+

Use the program filters and check the weekly schedule. You can ask about any class from its timetable row.

Are prices and class times final?+

No. This is a fictional portfolio demonstration, so all plans and timetables are editable examples.
