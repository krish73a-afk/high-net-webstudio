# Apex Academy — Basic Education Website Demo

A hand-designed fictional academy website made for the High Net Webstudio portfolio. No framework required.

## Run

Open `index.html` in a browser (or with VS Code Live Server). It includes `style.css`, `script.js`, and an original vector illustration at `assets/study-desk.svg`.

## Customize

- **Name, headlines, sections, course cards, contact copy:** `index.html`.
- **Colours, type, spacing, rounded corners:** `style.css`, especially the variables at the top.
- **Course-detail text:** the `courses` object near the top of `script.js`.
- **Example day-switcher data:** the `schedule` object in `script.js`.
- **Illustration:** `assets/study-desk.svg` (original source artwork, editable SVG).
- **Portfolio demo URL:** when placed in `High_Net_Webstudio_V3/demos/education/apex-basic/`, set the `url` for `Apex Academy` in the main portfolio's `demos.js` to `demos/education/apex-basic/index.html`.

## Important limitations

This is a fictional **concept**, not a real academy. The programme content, times and contact form are examples. The enquiry preview checks required fields, displays a confirmation, clears the entries, and **does not send or store personal information**. For a real client's website, configure their approved contact endpoint or form provider with suitable privacy disclosures. Do not describe it as a functioning real admission system yet.

All vector artwork was created for this project. The website functions without a network connection; remote Google Fonts will gracefully fall back to locally available fonts.

## Design rationale

The page pattern combines an introductory hero, fast course discovery, clear academic approach, schedule example, simple FAQs and an enquiry section. The design is informed by a comparative review of Khan Academy India, Coursera, edX, Unacademy, Physics Wallah, Vedantu, ALLEN, BYJU'S, Udemy and British Council. None of their source code, brand assets or text is reused.
